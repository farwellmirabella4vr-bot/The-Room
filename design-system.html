Design System

One palette, one pattern library, one type pairing, one base component set -- meant to make every room feel like one connected building instead of a pile of unrelated apps, while each room keeps its own character on top. An equal blend of three real traditions: Persian girih, Moroccan zellij, and Ottoman Iznik. Geometric, botanical, and architectural only -- no figurative imagery, no calligraphy or religious text, no crescent-and-star.

Pattern Library

Real construction, not an approximated look — see the comments in design-system/patterns.css for exactly how each is built.

Girih (Persian)
{8/3} star-polygon strapwork, stroked not filled — an all-over field pattern.
Zellij (Moroccan)
Star-and-cross mosaic — filled tile pieces with grout-line strokes.
Iznik (Ottoman)
Stylized tulip border strip — botanical, meant for framing, not an all-over field.
